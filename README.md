# Ju Terra

Site institucional da Ju Terra, cliente da 4est, construído com
[Next.js](https://nextjs.org) (App Router) e Tailwind CSS v4.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Estrutura

- `src/app` — layout, metadata e página principal (App Router).
- `src/components` — seções da página (a criar conforme o conteúdo do site
  for definido).
- `public` — imagens, ícones e fontes da marca.

## Build

```bash
npm run build
npm run start
```
